# 鲁信环境 · 企业制度门户

> 把公司内部制度做成网页：**美观、可搜索、可评论、带管理后台**。
> 纯 Python 标准库实现，零第三方依赖，双击即可运行。

---

## 一、快速启动

### Windows

双击 `启动.bat`，或在命令行执行：

```bash
python server.py
```

启动后访问：

| 入口 | 地址 | 说明 |
| --- | --- | --- |
| 前台门户 | http://127.0.0.1:8080 | 员工查阅、搜索、评论 |
| 管理后台 | http://127.0.0.1:8080/admin | 管理员维护制度 |

**默认管理员账号：`admin`　密码：`admin888`**（首次登录后请立即修改）

## 二、功能清单

### 前台门户（员工使用）

- **首页** —— 英雄区 + 数据概览（现行制度数 / 条款数 / 查阅量 / 建言数）、核心制度推荐、全库分类浏览
- **全部制度** —— 按分类（人力资源 / 财务制度 / 信息技术 / 综合管理 …）筛选
- **制度阅读** ——
  - 左侧章节目录，点击直达条款
  - 阅读进度条 + 目录自动高亮
  - 顶部元信息：分类、版本号、施行日期、发布部门、查阅量
  - 「打印 / 导出 PDF」（自动隐藏导航与页脚，输出干净的文档版）
  - 「复制链接」便于在群内分享
- **全文检索** —— 关键词**精确到条款**，命中处高亮，并显示所属章节与条款号
- **评论建言** —— 实名提交，提交后进入待审核队列；审核通过后公开展示
- **使用说明** —— 门户定位、使用方法、制度效力顺序、反馈渠道

### 管理后台（管理员使用）

| 模块 | 能力 |
| --- | --- |
| 数据概览 | 四项 KPI、查阅量排行条形图、最新建言、制度清单总览、待审提醒 |
| 制度管理 | 新增 / 编辑 / 删除、分类与版本维护、发布状态切换（已发布 / 草稿 / 已归档）、名称筛选 |
| 内容编辑器 | Markdown 编辑 + **实时预览** + 文件上传（Word / PDF / 图片），支持表格语法 |
| 评论审核 | 待审 / 已通过 / 已拒绝 三态筛选，一键通过、拒绝、删除 |
| 账号管理 | 新增管理员、修改密码、删除账号 |
| 系统设置 | 门户名称与标语、**评论审核开关**（先审后发 / 即时发布）、修改自身密码 |
| 系统日志 | 登录、新增 / 修改 / 删除制度、评论审核、文件上传等操作全程留痕 |

## 五、接线到公司内网

当前为本地单机运行。若要给全公司使用，建议：

1. **部署到内网服务器**
   把 `policysite` 整个目录拷到一台常开的服务器，用
   `python server.py` 或注册为 Windows 服务运行。
   改端口：设置环境变量 `PORT=80` 后再启动。

2. **接入统一认证**（可选）
   目前为独立账号体系。若公司已有企业微信 / 统一身份认证（SSO），
   可将 `/api/login` 改为调用企微接口获取 `userid`，实现免密登录，
   同时在评论中自动带出真实姓名与部门，省去手工填写。

3. **数据定期备份**
   备份 `data/portal.db` 与 `uploads/` 两个目录即可。

4. **权限细化**（可选）
   数据库 `users.role` 字段已预留 `admin` / `editor` 两种角色，
   后续可细化到「按分类授权」——如财务部只能维护财务类制度。

## 六、常见问题

**Q：端口 8080 被占用怎么办？**
设置环境变量后启动：`set PORT=8090 && python server.py`

**Q：忘记管理员密码？**
删除 `data/portal.db` 会重置全部数据（含制度与评论）。若只想重置密码，
可用 Python 执行：

```python
import sqlite3, hashlib, secrets
c = sqlite3.connect('data/portal.db')
salt = secrets.token_hex(8)
c.execute("UPDATE users SET password=?, salt=? WHERE username='admin'",
          (hashlib.sha256(('新密码' + salt).encode()).hexdigest(), salt))
c.commit()
```

**Q：如何把 Word/PDF 制度快速录入？**
后台「新增制度」→ 编辑器切到「上传文件」标签上传原件存档，
再把正文粘贴到「编辑」标签（Markdown 语法：`## 第一章`、`### 第一条`、`| 表格 |`）。
若需批量自动解析 PDF，可复用本次解析《员工手册》的脚本思路。

**Q：评论为什么看不到？**
默认「先审后发」。管理员在后台「评论审核」中通过后即公开展示；
也可在「系统设置」中改为「即时发布」。
